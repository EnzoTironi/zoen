# Blocked report

Use this when execution cannot continue without inventing semantics or falsely passing evidence.

- Ticket and current commit/lock/profile.
- Exact missing or conflicting prerequisite, with spec section and observed evidence.
- Last safe state; any partial code or staged data; confirm no unauthorized external effect.
- Smallest decision/input needed, responsible function and affected downstream tickets/routes.
- Work explicitly not attempted; rollback/cleanup required.

Do not replace a live integration with a simulator and call it admitted. Do not broaden credentials, drop a required test, reinterpret a timeout as failure or select an unapproved framework to get past the block. Independent unrelated ready tickets can continue through the planner.
