## Gates (summary)

Work gates commonly include `G-TIP`, `G-CI`, `G-RESOURCES`. Human/ops gates (`H-01`, `H-02`, `G-OPS`, `G-STORAGE-FENCE`, `G-PROVIDER`) block qualification — they are not placeholders to bypass. ZA-26 closes only the **selected** frontier; it does not accept blocked full-D03/D05 or the long horizon.

Composition, migration ledger, manifests, CI, and source moves are **reserved** — one owner at a time. Each code PR starts from a current green base and earns fresh required checks on its own head.
