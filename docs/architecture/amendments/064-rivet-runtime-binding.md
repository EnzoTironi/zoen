# ADR-064 — Rivet immutable runtime binding

Status: accepted design amendment for v4; implementation/qualification pending. Date: 2026-09-04.

## Decision

Qualify Dynamic Apps Core as first specialized backend adapter, outside authority; internal deployment does not activate a public Zoen app.

## Consequences and rejected alternatives

Immutable internal slots + current Ontology publication binding. Actual API/containment/recovery probes remain gates, not assumed support. Rejected: per-surface data backends, app-local permission stores, bearer data links, deploy-equals-publish, copied policy engines and framework-driven domain meaning. Preserve all original C001–C157 scope; no technology qualification can be fabricated to satisfy the ambition.

## Normative contract and proof

[runtime contract](../rivet-adapter.md), [sources](../../lineage/source-ledger.md). Per-ticket AC/NEG/BOUNDARY checks, current independent evidence and required operating gates control admission. Source docs inform the design but are not real product tests.

## Supersession

Refines v3 active contracts and SPEC-035; no modification to immutable historical v3/v2 input. Conflicting historical instructions defer to this amendment and the v4 constitution. Changed accepted implementation evidence must be reopened before reuse.
