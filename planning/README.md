# Registros de execução

Não carregar todos estes JSONs como contexto. `workspace.py packet` seleciona um ticket.

`catalog.json` é a fonte revisada de specs/tickets; `module-recipes.json` contém algoritmos; `files.json` registra planos e candidatos; `check-map.json` é derivado; `state.json` mantém aceite/evidência separado. O gerador não aceita tickets nem habilita providers.

`candidate-files.json` é a prova de preservação nesta entrega; mudanças futuras legítimas precisam de nova evidência e registro explícito, nunca adulteração do hash histórico. `runtime-sources.json` e tsconfigs selecionam apenas código real. `path-bindings.json` registra os ajustes da emenda 066.
